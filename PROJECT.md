# Google Calendar Visualizer

A Chrome extension that adds personalized AI-generated illustrations to Google Calendar events.

Users can create reusable visual concepts for:

- People
- Places
- Activities
- Other recurring concepts

Concepts can be created using:

- Text descriptions
- Uploaded images
- Images and text together

The extension will recognize concepts in Google Calendar events and automatically generate or reuse personalized event-background illustrations.

## MVP Scope

The first version will support:

- Google Calendar in Chrome
- Custom event backgrounds
- People, place, and activity concepts
- AI-assisted concept creation
- Event concept matching
- AI-generated event illustrations
- Image caching and reuse
- Manual regenerate / disable controls

## Out of Scope for MVP

- Native mobile app
- Full custom calendar client
- Multi-device cloud sync
- Other calendar providers
- Social or shared concepts
